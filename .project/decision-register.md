# Decision Register

## DEC-001: Next.js + FastAPI Architecture
- **Status:** APPROVED
- **Rationale:** Premium UI capabilities (Next.js) decoupled from heavy, native ML/QML dependencies (FastAPI).

## DEC-002: REST API with multipart/form-data
- **Status:** APPROVED
- **Rationale:** Superior to GraphQL for binary image uploads and flat inference payload responses.

## DEC-003: Local PoW vs Render Cloud Deployment
- **Status:** APPROVED
- **Rationale:** Local deployment for Phase 1 ensures 0 network latency during live pitch. Render deployment scheduled for Phase 4.

## DEC-004: Phase 3 Academic Publication
- **Status:** APPROVED
- **Rationale:** Paper must be published prior to Grand Finale to strengthen the project's authority.
