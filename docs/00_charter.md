# Project Charter

## Identity
- **Name:** Anatomy-Grounded Hybrid Quantum AI for Early Disease Detection
- **Target:** SIH26139 (Software)

## Goals
- **Phase 1 (Immediate):** Internal PoW (Next.js/FastAPI, QSVM benchmark).
- **Phase 2:** SIH Pre-Finale Refinement (TBX11K, VQC, Cross-dataset).
- **Phase 3:** Post-SIH Academic Publication (Publish before finale).
- **Phase 4:** SIH Grand Finale (Multi-disease, Render Cloud Deployment).

## Explicit Non-Goals
- Clinical-grade autonomous diagnosis.
- Pre-assuming quantum advantage.
- Heavy browser-side ML computation.
- Monolithic architectures.
